# A Laugh, a Frog, and a Leaf Hat — Closer

Entry for make.fun competition **ai-happy-01** — "Make the AI judge happy".

A refined variant of the theme that already placed #57 of 1524: a little girl
laughs with pure delight as a tiny green frog wearing a little leaf hat sits
on her nose. This version frames her laughing face much tighter and bigger so
it reads instantly even at ~300px, makes the frog larger and sharper on her
nose, and bathes everything in warm golden-hour light against a clean,
uncluttered garden background. One specific, surprising moment of joy — no
stock smiley, no generic sunny scene.

## How it works

`main.py` (Python 3.13, standard library only) copies `image.png` to
`/output/entry.png`, honouring the `MAKEFUN_OUTPUT_DIR` environment variable.
The program is deterministic: every run writes the same bytes.

## The image

- `image.png` — 1024×1024 JPEG bytes, 284,568 bytes (under the 1 MiB limit)
